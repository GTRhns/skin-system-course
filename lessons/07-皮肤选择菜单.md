# 第 7 课：皮肤选择菜单

> 覆盖源码第 676-963 行。这一课讲清楚：皮肤选择菜单怎么显示、怎么分页、怎么翻页、怎么选中皮肤。

---

## 7.1 三个快捷命令（第 756-775 行）

```pawn
public cmdSkinSelectT(const id) {
    g_iSkinSelectType[id] = 0;
    g_iSkinSelectPage[id] = 0;
    showSkinSelectMenu(id);
    return PLUGIN_HANDLED;
}

public cmdSkinSelectCT(const id) {
    g_iSkinSelectType[id] = 1;
    g_iSkinSelectPage[id] = 0;
    showSkinSelectMenu(id);
    return PLUGIN_HANDLED;
}

public cmdSkinSelectKnife(const id) {
    g_iSkinSelectType[id] = 2;
    g_iSkinSelectPage[id] = 0;
    showSkinSelectMenu(id);
    return PLUGIN_HANDLED;
}
```

这三个函数对应 `/skin_t`、`/skin_ct`、`/skin_knife` 命令。逻辑一模一样：设置类型 → 翻页归零 → 显示菜单。

> 注意：这三个函数**没有** `is_user_connected` 防御检查。因为 `register_clcmd` 只会对已连接的玩家触发命令，所以这里省略了检查。这是和 `cmdSkinMain` 的一个小差异。

## 7.2 is_skin_owned：检查是否拥有（第 778-794 行）

```pawn
bool:is_skin_owned(const id, const iType, const iModelIdx) {
    new iOwnedCount, iOwned[MAX_OWNED_SKINS];
    if (iType == 0) {
        iOwnedCount = g_iOwnedTCount[id];
        for (new i = 0; i < iOwnedCount; i++) iOwned[i] = g_iOwnedT[id][i];
    } else if (iType == 1) {
        iOwnedCount = g_iOwnedCTCount[id];
        for (new i = 0; i < iOwnedCount; i++) iOwned[i] = g_iOwnedCT[id][i];
    } else {
        iOwnedCount = g_iOwnedKnifeCount[id];
        for (new i = 0; i < iOwnedCount; i++) iOwned[i] = g_iOwnedKnife[id][i];
    }
    for (new i = 0; i < iOwnedCount; i++) {
        if (iOwned[i] == iModelIdx) return true;
    }
    return false;
}
```

这个函数判断玩家是否拥有某个皮肤。

1. 根据类型（T/CT/刀）把玩家的已拥有皮肤索引**复制**到临时数组 `iOwned`
2. 遍历 `iOwned`，`if (iOwned[i] == iModelIdx)` —— 如果找到目标索引，返回 `true`（拥有）
3. 遍历完都没找到，返回 `false`（没拥有）

> 注意：这里先把数据复制到临时数组再遍历，其实可以**直接遍历** `g_iOwnedT[id]`，不需要复制。这是一个可以优化的小地方，但不影响功能。

> 注意 `bool:` 前缀：声明这个函数返回布尔值（true/false）。

## 7.3 showSkinSelectMenu：显示选择菜单（第 796-880 行）

### 7.3.1 防御检查（第 797 行）

```pawn
if (!is_user_connected(id)) return;
```

### 7.3.2 读取状态（第 799-800 行）

```pawn
new iType = g_iSkinSelectType[id];
new iPage = g_iSkinSelectPage[id];
```

从全局变量读取玩家正在浏览的类型和页码。

### 7.3.3 根据类型选择数组（第 802-823 行）

```pawn
new Array:aModels, Array:aModelNames;
new iSelected, szTitle[32];

if (iType == 0) {  // T
    aModels = g_aTModels;
    aModelNames = g_aTModelNames;
    iSelected = g_iSelectedT[id];
    copy(szTitle, charsmax(szTitle), "T(土匪)皮肤");
}
else if (iType == 1) {  // CT
    ...
}
else if (iType == 2) {  // Knife
    ...
}
```

根据类型，把对应的模型数组、名称数组、当前选中值、标题取出来。这样下面构建菜单的代码可以**统一处理**三种类型，不用每种写一遍。

### 7.3.4 空数组检查（第 825-829 行）

```pawn
new iTotalModels = ArraySize(aModels);
if (iTotalModels <= 0) {
    client_print(id, print_chat, "[SkinSystem] 暂无可用皮肤");
    return;
}
```

`if (iTotalModels <= 0)` —— 如果这种类型一个皮肤都没有，提示玩家并退出。

### 7.3.5 计算分页范围（第 831-834 行）

```pawn
new iStart = iPage * 7;
new iEnd = iStart + 7;
if (iEnd > iTotalModels) iEnd = iTotalModels;
```

- `iStart = iPage * 7` —— 本页起始索引（每页 7 个）
- `iEnd = iStart + 7` —— 本页结束索引
- `if (iEnd > iTotalModels) iEnd = iTotalModels` —— **如果超出总数，截断到总数**（最后一页可能不满 7 个）

> 这个 `if` 是防止最后一页显示空白项。

### 7.3.6 构建菜单标题（第 836-837 行）

```pawn
new szMenu[512], iLen;
iLen = formatex(szMenu, charsmax(szMenu), "\y%s \r- \w选择皮肤^n\y─────── 第%d页 ───────^n^n", szTitle, iPage + 1);
```

标题显示皮肤类型和页码。`iPage + 1` 是因为页码从 0 开始，显示给玩家要 +1（第 1 页、第 2 页...）。

### 7.3.7 声明按键掩码（第 841 行）

```pawn
new iKeys = (1<<0)|(1<<1)|(1<<2)|(1<<3)|(1<<4)|(1<<5)|(1<<6)|(1<<7)|(1<<8)|(1<<9);
```

允许按 0-9 所有键。因为菜单有 7 个皮肤位 + 翻页键（0 和 9）。

### 7.3.8 遍历本页皮肤（第 843-857 行）

```pawn
for (new i = iStart; i < iEnd; i++) {
    iModelIdx = i;  // 直接使用模型索引
    ArrayGetString(aModelNames, iModelIdx, szName, charsmax(szName));
    bOwned = is_skin_owned(id, iType, iModelIdx);

    new iSlot = i - iStart + 1;
    new szMarker[8] = "";
    if (iModelIdx == iSelected) copy(szMarker, charsmax(szMarker), " ✓");

    if (bOwned) {
        iLen += formatex(szMenu[iLen], charsmax(szMenu) - iLen, "\r%d. \w%s%s^n", iSlot, szName, szMarker);
    } else {
        iLen += formatex(szMenu[iLen], charsmax(szMenu) - iLen, "\r%d. \d%s \r(未解锁)^n", iSlot, szName);
    }
}
```

逐项处理：

1. `iModelIdx = i` —— 模型索引就是数组下标
2. `ArrayGetString` 取出皮肤名称
3. `bOwned = is_skin_owned(...)` —— 判断是否拥有
4. `iSlot = i - iStart + 1` —— 计算菜单槽位（1-7）
5. `if (iModelIdx == iSelected)` —— **如果是当前选中的皮肤**，加一个 `✓` 标记
6. `if (bOwned)` —— 拥有则显示白色，**否则**显示灰色 + "(未解锁)"

> 注意 `\d` 是灰色颜色代码。未解锁的皮肤用灰色显示，玩家一眼就能看出哪些能用、哪些不能用。

### 7.3.9 填充空位（第 860-862 行）

```pawn
for (new i = iEnd; i < iStart + 7; i++) {
    iLen += formatex(szMenu[iLen], charsmax(szMenu) - iLen, "^n");
}
```

最后一页如果不满 7 个，用空行填充，保持菜单高度一致。

### 7.3.10 翻页按钮（第 866-877 行）

```pawn
iLen += formatex(szMenu[iLen], charsmax(szMenu) - iLen, "\y───────^n");

if (iPage > 0) {
    iLen += formatex(szMenu[iLen], charsmax(szMenu) - iLen, "\r0. \w上一页^n");
} else {
    iLen += formatex(szMenu[iLen], charsmax(szMenu) - iLen, "\r0. \w返回^n");
}

if (iTotalModels > iEnd) {
    iLen += formatex(szMenu[iLen], charsmax(szMenu) - iLen, "\r9. \w下一页^n");
} else {
    iLen += formatex(szMenu[iLen], charsmax(szMenu) - iLen, "^n");
}
```

两个 `if` 判断：
- `if (iPage > 0)` —— 不是第一页，显示"上一页"；**否则**显示"返回"
- `if (iTotalModels > iEnd)` —— 后面还有皮肤，显示"下一页"；**否则**不显示

> 这两个 `if` 是**动态菜单**的精髓：根据当前状态决定显示什么按钮。

### 7.3.11 显示菜单（第 879 行）

```pawn
show_menu(id, iKeys, szMenu, -1, "HnsSkinSkinSelect");
```

菜单名是 `"HnsSkinSkinSelect"`，对应 `plugin_init` 里注册的 `handleSkinSelectMenu`。

## 7.4 handleSkinSelectMenu：处理按键（第 882-957 行）

### 7.4.1 读取状态（第 885-893 行）

```pawn
new iType = g_iSkinSelectType[id];
new iPage = g_iSkinSelectPage[id];

new Array:aModels;
if (iType == 0) aModels = g_aTModels;
else if (iType == 1) aModels = g_aCTModels;
else aModels = g_aKnifeModels;
new iTotalModels = ArraySize(aModels);
```

### 7.4.2 下一页（第 897-905 行）

```pawn
if (key == 8) {  // 下一页
    new iMaxPage = ((iTotalModels - 1) / 7);
    if (iPage < iMaxPage) {
        g_iSkinSelectPage[id]++;
    }
    showSkinSelectMenu(id);
    return PLUGIN_HANDLED;
}
```

`key == 8` 对应按"9"键（菜单里显示"9. 下一页"）。

`iMaxPage = ((iTotalModels - 1) / 7)` —— 计算最大页码。比如 15 个皮肤，(15-1)/7 = 2，最大页码是 2（第 3 页）。

`if (iPage < iMaxPage)` —— **如果还没到最后一页**，页码 +1。这个 `if` 防止无限翻页（翻过最后一页）。

> 注意：如果已经在最后一页，按"下一页"不会翻页，但菜单会重新显示（相当于刷新）。

### 7.4.3 上一页 / 返回（第 908-916 行）

```pawn
if (key == 9) {  // 上一页 或 返回
    if (iPage > 0) {
        g_iSkinSelectPage[id]--;
        showSkinSelectMenu(id);
    }
    return PLUGIN_HANDLED;
}
```

`key == 9` 对应按"0"键。

`if (iPage > 0)` —— **如果不是第一页**，页码 -1 并重新显示（上一页）。如果是第一页，什么都不做（菜单关闭 = 返回）。

> 注意：第一页按"0"是返回，但代码里"什么都不做"就关闭了菜单。这和主菜单的"退出"行为一致。

### 7.4.4 选择皮肤（第 918-956 行）

```pawn
new iSlot = key;  // key已经是0-indexed，直接使用
new iModelIdx = iPage * 7 + iSlot;

new iMaxPage = ((iTotalModels - 1) / 7);
if (g_iSkinSelectPage[id] > iMaxPage) g_iSkinSelectPage[id] = iMaxPage;
if (g_iSkinSelectPage[id] < 0) g_iSkinSelectPage[id] = 0;

if (iModelIdx >= 0 && iModelIdx < iTotalModels) {
    if (!is_skin_owned(id, iType, iModelIdx)) {
        client_print(id, print_chat, "[SkinSystem] 该皮肤尚未解锁！请联系管理员获取");
        showSkinSelectMenu(id);
        return PLUGIN_HANDLED;
    }

    if (iType == 0) {  // T
        g_iSelectedT[id] = iModelIdx;
        save_player_skins(id);
        apply_model(id);
    }
    else if (iType == 1) {  // CT
        g_iSelectedCT[id] = iModelIdx;
        save_player_skins(id);
        apply_model(id);
    }
    else if (iType == 2) {  // Knife
        g_iSelectedKnife[id] = iModelIdx;
        save_player_skins(id);
        apply_model(id);
    }

    set_task(0.1, "taskRefreshSkinMenu", id);
}

return PLUGIN_HANDLED;
```

1. `iModelIdx = iPage * 7 + iSlot` —— 计算选中的绝对索引（页码 × 7 + 槽位）
2. 两个 `if` 修正页码范围（防止异常值）
3. `if (iModelIdx >= 0 && iModelIdx < iTotalModels)` —— **索引合法才处理**
4. `if (!is_skin_owned(...))` —— **没拥有就提示并返回**，不允许选择
5. 拥有则：记录选择 → 保存存档 → 应用模型
6. `set_task(0.1, "taskRefreshSkinMenu", id)` —— 延迟 0.1 秒刷新菜单（让玩家看到 ✓ 标记）

> 注意第 4 步的 `if`：这是**权限控制**的核心。玩家只能选自己拥有的皮肤，没拥有的皮肤即使显示在菜单里，点了也会被拒绝。

## 7.5 taskRefreshSkinMenu：刷新菜单（第 959-963 行）

```pawn
public taskRefreshSkinMenu(const id) {
    if (is_user_connected(id)) {
        showSkinSelectMenu(id);
    }
}
```

延迟 0.1 秒后重新显示菜单，让玩家看到刚选的皮肤带上了 ✓。

> 为什么要延迟？因为 `apply_model` 之后立即刷新菜单，可能玩家还没反应过来。延迟 0.1 秒让画面稳定。

## 7.6 小结

皮肤选择菜单的完整流程：

```
打开菜单
  → showSkinSelectMenu：按类型取数组 → 分页 → 构建菜单 → 显示
玩家按键
  → handleSkinSelectMenu：
      key=8 → 下一页（有边界检查）
      key=9 → 上一页/返回
      其他 → 选中皮肤（检查拥有 → 记录 → 保存 → 应用 → 刷新）
```
