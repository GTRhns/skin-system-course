# 第 10 课：工具函数

> 覆盖源码第 1940-2176 行。这一课讲清楚：插件底层的工具函数——检查拥有、发放、收回、查找玩家、查找皮肤、清理内存。

---

## 10.1 has_skin：检查是否拥有（第 1945-1972 行）

```pawn
stock bool:has_skin(const id, const iType, const iSkinIndex) {
    if (iType == 0) {
        {
            for (new i = 0; i < g_iOwnedTCount[id]; i++) {
                if (g_iOwnedT[id][i] == iSkinIndex) {
                    return true;
                }
            }
        }
    } else if (iType == 1) {
        {
            for (new i = 0; i < g_iOwnedCTCount[id]; i++) {
                if (g_iOwnedCT[id][i] == iSkinIndex) {
                    return true;
                }
            }
        }
    } else if (iType == 2) {
        {
            for (new i = 0; i < g_iOwnedKnifeCount[id]; i++) {
                if (g_iOwnedKnife[id][i] == iSkinIndex) {
                    return true;
                }
            }
        }
    }
    return false;
}
```

这个函数判断玩家是否拥有某个皮肤。根据类型选择对应的数组，遍历查找。

- `if (iType == 0)` —— T 皮肤，遍历 `g_iOwnedT[id]`
- `else if (iType == 1)` —— CT 皮肤
- `else if (iType == 2)` —— 刀皮肤

内层 `if (g_iOwnedT[id][i] == iSkinIndex)` —— **如果找到匹配的索引**，立即 `return true`（拥有）。

遍历完都没找到，`return false`（没拥有）。

> 注意：这里 `iType` 是 0/1/2（T/CT/刀）。但第 8 课里 `g_iGiveType` 用的是 1/2/3。**两套编码不同**，调用时要小心转换。这是这个插件的一个容易踩坑的地方。

> 注意那些多余的 `{ }` 大括号：这是源码里历史遗留的格式问题（可能从别的代码复制过来），不影响功能，只是难看。

## 10.2 give_skin：发放皮肤（第 1975-2003 行）

```pawn
stock give_skin(const id, const iType, const iSkinIndex) {
    // 检查是否已拥有
    if (has_skin(id, iType, iSkinIndex)) {
        return;
    }

    if (iType == 0) {
        {
            if (g_iOwnedTCount[id] < MAX_OWNED_SKINS) {
                g_iOwnedT[id][g_iOwnedTCount[id]] = iSkinIndex;
                g_iOwnedTCount[id]++;
            }
        }
    } else if (iType == 1) {
        ...
    } else if (iType == 2) {
        ...
    }
}
```

发放皮肤 = 把皮肤索引加进玩家的"已拥有"数组。

1. `if (has_skin(id, iType, iSkinIndex))` —— **如果已经拥有**，直接返回（不重复发放）
2. `if (g_iOwnedTCount[id] < MAX_OWNED_SKINS)` —— **如果还没满**（少于 64 个），把索引加到数组末尾，数量 +1

> 注意 `g_iOwnedT[id][g_iOwnedTCount[id]] = iSkinIndex` —— 用当前数量作为下标，把新皮肤追加到数组末尾。然后 `g_iOwnedTCount[id]++` 数量加一。

> `if (g_iOwnedTCount[id] < MAX_OWNED_SKINS)` 是**防溢出**：如果玩家已经有 64 个皮肤了，就不再添加，防止数组越界。

## 10.3 take_skin：收回皮肤（第 2006-2055 行）

```pawn
stock take_skin(const id, const iType, const iSkinIndex) {
    if (iType == 0) {
        {
            for (new i = 0; i < g_iOwnedTCount[id]; i++) {
                if (g_iOwnedT[id][i] == iSkinIndex) {
                    // 移除：将后面的元素前移
                    for (new j = i; j < g_iOwnedTCount[id] - 1; j++) {
                        g_iOwnedT[id][j] = g_iOwnedT[id][j + 1];
                    }
                    g_iOwnedTCount[id]--;
                    // 如果当前选择的就是这个皮肤，重置
                    if (g_iSelectedT[id] == iSkinIndex) {
                        g_iSelectedT[id] = 0; // 回到默认
                    }
                    break;
                }
            }
        }
    }
    ...
}
```

收回皮肤 = 从"已拥有"数组里删除。

1. 外层 `for` 遍历找目标索引
2. `if (g_iOwnedT[id][i] == iSkinIndex)` —— **找到了**
3. 内层 `for` 把后面的元素**前移**（覆盖掉被删除的位置）
4. `g_iOwnedTCount[id]--` —— 数量减一
5. `if (g_iSelectedT[id] == iSkinIndex)` —— **如果玩家当前选的就是这个皮肤**，重置为默认（索引 0）
6. `break` —— 删除完成，跳出循环

> 内层 `for (new j = i; j < g_iOwnedTCount[id] - 1; j++)` 是**数组删除的标准算法**：把被删元素后面的所有元素往前挪一位，覆盖掉被删的位置。比如 `[1,2,3,4]` 删 2 → `[1,3,4,4]` → 数量减一 → `[1,3,4]`。

> `if (g_iSelectedT[id] == iSkinIndex)` 这个 `if` 很关键：如果玩家正穿着这个皮肤，管理员收回了，玩家的选择就失效了。重置为 0（默认皮肤）保证玩家还有皮肤可用。

## 10.4 find_player_by_name：按名字查找玩家（第 2075-2098 行）

```pawn
stock find_player_by_name(const szName[]) {
    new iPlayers[MAX_PLAYERS], iNum;
    get_players(iPlayers, iNum, "c");

    // 精确匹配
    for (new i = 0; i < iNum; i++) {
        new szPlayerName[32];
        get_user_name(iPlayers[i], szPlayerName, charsmax(szPlayerName));
        if (equal(szPlayerName, szName)) {
            return iPlayers[i];
        }
    }

    // 部分匹配
    for (new i = 0; i < iNum; i++) {
        new szPlayerName[32];
        get_user_name(iPlayers[i], szPlayerName, charsmax(szPlayerName));
        if (containi(szPlayerName, szName) >= 0) {
            return iPlayers[i];
        }
    }

    return 0;
}
```

两级查找：
1. **精确匹配**：`if (equal(szPlayerName, szName))` —— 名字完全一样才匹配
2. **部分匹配**：`if (containi(szPlayerName, szName) >= 0)` —— 名字**包含**输入内容就匹配（不区分大小写）

找不到返回 0（无效玩家 id）。

> 为什么先精确后部分？因为精确匹配更可靠。如果玩家叫"小明"，输入"小明"应该精确匹配；如果输入"小"，部分匹配能找到"小明"、"小红"等。先精确后部分，保证最准确的优先。

## 10.5 find_skin_index_by_name：按名字查找皮肤（第 2101-2132 行）

```pawn
stock find_skin_index_by_name(const iType, const szName[]) {
    new Array:aNames;
    if (iType == 0) {
        aNames = g_aTModelNames;
    } else if (iType == 1) {
        aNames = g_aCTModelNames;
    } else if (iType == 2) {
        aNames = g_aKnifeModelNames;
    } else {
        return -1;
    }

    new iSize = ArraySize(aNames);
    for (new i = 0; i < iSize; i++) {
        new szSkinName[MAX_SKIN_NAME];
        ArrayGetString(aNames, i, szSkinName, charsmax(szSkinName));
        if (equali(szSkinName, szName)) {
            return i;
        }
    }

    // 部分匹配
    for (new i = 0; i < iSize; i++) {
        new szSkinName[MAX_SKIN_NAME];
        ArrayGetString(aNames, i, szSkinName, charsmax(szSkinName));
        if (containi(szSkinName, szName) >= 0) {
            return i;
        }
    }

    return -1;
}
```

和 `find_player_by_name` 逻辑一样，只是查的是皮肤名称数组。`else` 分支处理无效类型，返回 -1。

> 注意：这个函数在 v1.0.0 里**没有被调用**（`cmdGiveSkinCmd` 里是内联实现的查找逻辑）。它是一个"备用工具"，留着以后用。

## 10.6 cleanup_arrays：清理内存（第 2169-2176 行）

```pawn
stock cleanup_arrays() {
    if (g_aTModels != Invalid_Array) { ArrayDestroy(g_aTModels); g_aTModels = Invalid_Array; }
    if (g_aTModelNames != Invalid_Array) { ArrayDestroy(g_aTModelNames); g_aTModelNames = Invalid_Array; }
    if (g_aCTModels != Invalid_Array) { ArrayDestroy(g_aCTModels); g_aCTModels = Invalid_Array; }
    if (g_aCTModelNames != Invalid_Array) { ArrayDestroy(g_aCTModelNames); g_aCTModelNames = Invalid_Array; }
    if (g_aKnifeModels != Invalid_Array) { ArrayDestroy(g_aKnifeModels); g_aKnifeModels = Invalid_Array; }
    if (g_aKnifeModelNames != Invalid_Array) { ArrayDestroy(g_aKnifeModelNames); g_aKnifeModelNames = Invalid_Array; }
}
```

在 `plugin_end` 里调用，销毁所有动态数组，释放内存。

每个 `if (g_aTModels != Invalid_Array)` —— **如果数组句柄有效**，才销毁。销毁后把句柄重置为 `Invalid_Array`，防止二次销毁。

> 这是标准的资源清理模式：先检查是否有效，再释放，再标记为无效。

## 10.7 小结

工具函数是插件的"底层零件"：
- `has_skin` —— 检查拥有
- `give_skin` —— 发放（追加到数组）
- `take_skin` —— 收回（前移删除）
- `find_player_by_name` / `find_skin_index_by_name` —— 查找
- `cleanup_arrays` —— 清理
