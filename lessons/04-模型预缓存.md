# 第 4 课：模型预缓存

> 覆盖源码第 521-550 行。这一课讲清楚：为什么模型要预缓存，怎么预缓存。

---

## 4.1 什么是预缓存

CS 引擎有一个规则：**所有要用的模型、声音、贴图，必须在加载地图时提前注册**。这个注册过程就叫"预缓存"（precache）。

如果不预缓存，游戏里用到这个模型时，会显示成错误的紫色/黑色方块，甚至可能导致服务器崩溃。

`precache_model` 就是 AMXX 提供的预缓存函数。

## 4.2 precache_all_models：主函数（第 524-550 行）

```pawn
stock precache_all_models() {
    new szModel[MAX_MODEL_NAME];
    new i, iSize;

    // 普通T模型
    iSize = ArraySize(g_aTModels);
    for (i = 0; i < iSize; i++) {
        ArrayGetString(g_aTModels, i, szModel, charsmax(szModel));
        precache_model(szModel);
    }

    // 普通CT模型
    iSize = ArraySize(g_aCTModels);
    for (i = 0; i < iSize; i++) {
        ArrayGetString(g_aCTModels, i, szModel, charsmax(szModel));
        precache_model(szModel);
    }

    // 普通刀模型
    iSize = ArraySize(g_aKnifeModels);
    for (i = 0; i < iSize; i++) {
        ArrayGetString(g_aKnifeModels, i, szModel, charsmax(szModel));
        precache_model(szModel);
    }

    log_amx("[SkinSystem] 所有模型预缓存完成");
}
```

### 4.2.1 逐段分析

```pawn
new szModel[MAX_MODEL_NAME];
new i, iSize;
```

`szModel` 是临时缓冲区，用来存放从数组取出的模型路径。`i` 是循环变量，`iSize` 是数组大小。

```pawn
iSize = ArraySize(g_aTModels);
for (i = 0; i < iSize; i++) {
    ArrayGetString(g_aTModels, i, szModel, charsmax(szModel));
    precache_model(szModel);
}
```

1. `ArraySize(g_aTModels)` —— 获取 T 模型数组有多少个元素
2. `for (i = 0; i < iSize; i++)` —— 遍历每一个元素
3. `ArrayGetString(g_aTModels, i, szModel, ...)` —— 取出第 i 个模型路径
4. `precache_model(szModel)` —— 预缓存它

> 注意 `for` 循环的条件 `i < iSize`。这是一个典型的 `if` 式边界检查：当 `i` 等于 `iSize` 时循环结束，不会越界访问数组。

### 4.2.2 为什么写三遍

T、CT、刀各写了一遍几乎一样的循环。这其实是**重复代码**，可以合并成一个函数。但作者选择分开写，好处是逻辑清晰、一眼看懂；坏处是代码冗余。

> 这是很多初学插件都会遇到的取舍：可读性 vs 简洁性。v1.0.0 选择了可读性优先。

## 4.3 小结

预缓存的本质是"提前告诉引擎：这些模型我要用"。

```
遍历数组 → 取出路径 → precache_model
```
