## 0.1 我们学的到底是什么

这门课要讲透一个文件：`source/HnsSkin.sma`，一共 **2175 行**。

它是一个 **AMX Mod X（简称 AMXX）插件**，跑在 CS1.6 服务器上。它的作用，简单说就是：

> 让玩家在游戏里输入 `/skin`，弹出一个菜单，选一个皮肤，然后这个皮肤会一直跟着他，下次进服务器还在。

就这么一件事，代码写了 2175 行。为什么？因为"选皮肤"背后藏着很多细节：

- 皮肤从哪来？（配置文件）
- 模型什么时候加载？（预缓存）
- 玩家选了之后怎么记住？（存档）
- 管理员怎么给别人发皮肤？（权限 + 菜单）
- 换枪的时候皮肤会不会丢？（消息钩子）

这门课就是把这些细节**一个一个**挖出来。

## 0.3 关于 Pawn 语言

AMXX 插件用 **Pawn** 语言写（`.sma` 后缀）。它和 C 语言很像，但更简单。你只需要记住几个点：

- `new` 声明变量：`new iCount = 0;`
- `if / else` 判断：`if (条件) { ... } else { ... }`
- `for` 循环：`for (new i = 0; i < 10; i++) { ... }`
- `stock` 开头的函数：普通工具函数
- `public` 开头的函数：被 AMXX 框架调用的回调函数

这些都会在后面的课里反复出现，不用现在背。

## 0.4 一个插件的基本结构

任何一个 AMXX 插件，都有三个"生命周期函数"：

```pawn
public plugin_precache() { }   // 服务器启动时：加载模型、资源
public plugin_init() { }       // 插件初始化：注册命令、菜单、事件
public plugin_end() { }        // 插件卸载时：清理
```

我们这门课的主角 `HnsSkin.sma` 也是这个结构。第 2 课会详细讲。

## 0.6 怎么读源码

建议把 `source/HnsSkin.sma` 下载到本地，用支持行号的编辑器打开（记事本也行）。每一课都会标注"覆盖第 X 行到第 Y 行"，你跟着行号走就行。

## 0.7 小练习

1. 打开 `source/HnsSkin.sma`，数一数它有多少行。
2. 找到 `plugin_precache`、`plugin_init`、`plugin_end` 三个函数分别在哪个位置。
3. 找到 `#include` 开头的几行，数一数一共引用了几个头文件。
