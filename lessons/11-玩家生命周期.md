# 第 11 课：玩家生命周期

> 覆盖源码第 298-382 行。这一课讲清楚：玩家进服务器、出服务器、Steam 验证通过时，插件分别做了什么。

---

## 11.1 玩家生命周期总览

一个玩家在服务器上的完整生命周期：

```
玩家进入服务器 → client_putinserver（初始化 + 加载存档）
Steam 验证通过 → client_authorized（重新加载存档）
玩家离开服务器 → client_disconnected（保存存档）
```

这三个回调函数是 AMXX 自动调用的，我们只需要实现逻辑。

## 11.2 client_putinserver：玩家进入（第 301-331 行）

```pawn
public client_putinserver(id) {
    if (is_user_bot(id) || is_user_hltv(id)) {
        // 机器人/HLTV: 只设置默认模型，不加载存档
        g_iSelectedT[id] = 0;
        g_iSelectedCT[id] = 0;
        g_iSelectedKnife[id] = 0;
        g_iOwnedTCount[id] = 0;
        g_iOwnedCTCount[id] = 0;
        g_iOwnedKnifeCount[id] = 0;
        g_iSkinSelectType[id] = 0;
        g_iSkinSelectPage[id] = 0;
        g_iGiveTarget[id] = 0;
        g_iGiveType[id] = 0;
        g_iGivePage[id] = 0;
        g_szPlayerAuth[id][0] = EOS;
        g_szPlayerIP[id][0] = EOS;
        g_szPlayerName[id][0] = EOS;
        return;
    }

    // 重置所有数据
    reset_player_data(id);

    // 获取玩家标识信息
    get_user_authid(id, g_szPlayerAuth[id], charsmax(g_szPlayerAuth[]));
    get_user_ip(id, g_szPlayerIP[id], charsmax(g_szPlayerIP[]), 1);
    get_user_name(id, g_szPlayerName[id], charsmax(g_szPlayerName[]));

    // 加载存档
    load_player_skins(id);
}
```

### 11.2.1 机器人 / HLTV 分支（第 302-319 行）

```pawn
if (is_user_bot(id) || is_user_hltv(id)) {
    // 机器人/HLTV: 只设置默认模型，不加载存档
    ...
    return;
}
```

`if (is_user_bot(id) || is_user_hltv(id))` —— **如果是机器人（bot）或 HLTV 转播**，走特殊分支。

> 为什么机器人要特殊处理？因为机器人没有真实的 SteamID/IP，没有存档。给它们设置默认皮肤（索引 0），把各种状态清零，然后直接返回。

> 注意：这里给机器人设置了 `g_iSelectedT[id] = 0` 等，意味着机器人会使用索引 0 的皮肤（默认皮肤）。这样机器人看起来也正常。

### 11.2.2 真实玩家分支（第 321-331 行）

```pawn
// 重置所有数据
reset_player_data(id);

// 获取玩家标识信息
get_user_authid(id, g_szPlayerAuth[id], charsmax(g_szPlayerAuth[]));
get_user_ip(id, g_szPlayerIP[id], charsmax(g_szPlayerIP[]), 1);
get_user_name(id, g_szPlayerName[id], charsmax(g_szPlayerName[]));

// 加载存档
load_player_skins(id);
```

1. `reset_player_data(id)` —— 清空这个玩家槽位的所有数据（11.4 节）
2. 获取 SteamID、IP、名字，存到全局变量
3. `load_player_skins(id)` —— 加载存档（第 9 课）

> 为什么先重置再加载？因为玩家 id 是**复用的**。玩家 A 退出后，他的 id 可能被玩家 B 使用。如果不重置，B 会继承 A 的残留数据。先重置保证干净。

## 11.3 client_disconnected：玩家离开（第 336-342 行）

```pawn
public client_disconnected(id) {
    if (is_user_bot(id) || is_user_hltv(id)) {
        return;
    }

    save_player_skins(id);
}
```

玩家离开时：
1. `if (is_user_bot(id) || is_user_hltv(id))` —— 机器人/HLTV 直接返回（没有存档可存）
2. `save_player_skins(id)` —— 保存存档

> 注意：`client_disconnected` 里调用 `save_player_skins` 时，玩家可能已经"半断开"了，但 `is_user_connected` 可能仍返回真（因为断开过程是渐进的）。所以保存能成功。

## 11.4 reset_player_data：重置数据（第 365-382 行）

```pawn
stock reset_player_data(id) {
    g_iOwnedTCount[id] = 0;
    g_iOwnedCTCount[id] = 0;
    g_iOwnedKnifeCount[id] = 0;
    g_iSelectedT[id] = -1;
    g_iSelectedCT[id] = -1;
    g_iSelectedKnife[id] = -1;
    g_iSkinSelectType[id] = 0;
    g_iSkinSelectPage[id] = 0;

    g_iGiveTarget[id] = 0;
    g_iGiveType[id] = 0;
    g_iGivePage[id] = 0;

    g_szPlayerAuth[id][0] = EOS;
    g_szPlayerIP[id][0] = EOS;
    g_szPlayerName[id][0] = EOS;
}
```

把所有"每玩家"的状态清零：
- 拥有数量 → 0
- 当前选择 → -1（没选）
- 菜单状态 → 0
- 发放状态 → 0
- 标识字符串 → 空（`[0] = EOS` 表示第一个字符设为字符串结尾）

> 注意 `g_szPlayerAuth[id][0] = EOS` —— 这是把字符串的第一个字符设为 `\0`，即清空字符串。这是 Pawn 里清空字符串的标准写法。

## 11.5 client_authorized：Steam 验证通过（第 347-360 行）

```pawn
public client_authorized(id) {
    if (is_user_bot(id) || is_user_hltv(id)) {
        return;
    }

    new szAuth[MAX_AUTHID_LENGTH];
    get_user_authid(id, szAuth, charsmax(szAuth));

    // 如果SteamID不再是LAN，重新加载
    if (!equal(szAuth, "STEAM_ID_LAN") && !equal(szAuth, "VALVE_ID_LAN")) {
        copy(g_szPlayerAuth[id], charsmax(g_szPlayerAuth[]), szAuth);
        load_player_skins(id);
    }
}
```

### 11.5.1 为什么需要这个函数

在 `client_putinserver` 时，玩家的 SteamID 可能还没验证完（显示为 `STEAM_ID_LAN`）。等 Steam 验证通过后，`client_authorized` 会再次触发，此时才有真正的 SteamID。

### 11.5.2 重新加载（第 356-359 行）

```pawn
if (!equal(szAuth, "STEAM_ID_LAN") && !equal(szAuth, "VALVE_ID_LAN")) {
    copy(g_szPlayerAuth[id], charsmax(g_szPlayerAuth[]), szAuth);
    load_player_skins(id);
}
```

`if (!equal(szAuth, "STEAM_ID_LAN") && !equal(szAuth, "VALVE_ID_LAN"))` —— **如果 SteamID 不再是 LAN 占位符**（说明验证通过了，有真实 SteamID），就：
1. 更新存储的 SteamID
2. 重新加载存档（用真实 SteamID 查找）

> 这个 `if` 很关键：只有验证通过（有真实 SteamID）才重新加载。如果还是 LAN，说明是盗版玩家，不需要重新加载。

## 11.6 小结

玩家生命周期：

```
进入 → 机器人？→ 是：设默认皮肤
             → 否：重置数据 → 获取标识 → 加载存档
验证 → 有真实SteamID？→ 是：更新标识 → 重新加载存档
离开 → 机器人？→ 是：跳过
             → 否：保存存档
```
