## 8.1 权限检查函数：get_user_perm_level（第 2134-2166 行）

先看权限检查，因为后面所有发放命令都靠它。

```pawn
stock get_user_perm_level(const id) {
    new szAuth[MAX_AUTHID_LENGTH];
    get_user_authid(id, szAuth, charsmax(szAuth));

    // 盗版玩家用IP
    if (equal(szAuth, "STEAM_ID_LAN") || equal(szAuth, "VALVE_ID_LAN")) {
        get_user_ip(id, szAuth, charsmax(szAuth), 1);
    }

    new szKey[128];
    format(szKey, charsmax(szKey), "skinsys_perm_level_%s", szAuth);

    new szNumBuf[32];
    if (nvault_get(g_iVault, szKey, szNumBuf, charsmax(szNumBuf))) {
        return str_to_num(szNumBuf);
    }

    // 尝试旧格式键名
    if (contain(szAuth, "STEAM_") != -1) {
        format(szKey, charsmax(szKey), "skinsys_perm_%s", szAuth);
    } else {
        format(szKey, charsmax(szKey), "skinsys_permip_%s", szAuth);
    }

    new szVal[8];
    if (nvault_get(g_iVault, szKey, szVal, charsmax(szVal))) {
        return str_to_num(szVal);
    }

    return PERM_NONE;
}
```

### 8.1.1 获取标识（第 2136-2142 行）

```pawn
get_user_authid(id, szAuth, charsmax(szAuth));

if (equal(szAuth, "STEAM_ID_LAN") || equal(szAuth, "VALVE_ID_LAN")) {
    get_user_ip(id, szAuth, charsmax(szAuth), 1);
}
```

先拿 SteamID。`if (equal(szAuth, "STEAM_ID_LAN") || equal(szAuth, "VALVE_ID_LAN"))` —— **如果是盗版玩家**（SteamID 是 LAN 占位符），改用 IP 作为标识。

> `equal` 是精确字符串比较。盗版玩家没有真正的 SteamID，所以用 IP 代替。

### 8.1.2 读取权限（第 2144-2150 行）

```pawn
new szKey[128];
format(szKey, charsmax(szKey), "skinsys_perm_level_%s", szAuth);

new szNumBuf[32];
if (nvault_get(g_iVault, szKey, szNumBuf, charsmax(szNumBuf))) {
    return str_to_num(szNumBuf);

```

从 nvault 读取权限等级。`if (nvault_get(...))` —— **如果读取成功**（返回真），把字符串转成数字返回。

### 8.1.3 兼容旧格式（第 2152-2165 行）

```pawn
if (contain(szAuth, "STEAM_") != -1) {
    format(szKey, charsmax(szKey), "skinsys_perm_%s", szAuth);
} else {
    format(szKey, charsmax(szKey), "skinsys_permip_%s", szAuth);
}

new szVal[8];
if (nvault_get(g_iVault, szKey, szVal, charsmax(szVal))) {
    return str_to_num(szVal);

```

如果新格式没找到，尝试旧格式的键名。`if (contain(szAuth, "STEAM_") != -1)` —— 判断是正版（SteamID 含 "STEAM_"）还是盗版，用不同的旧键名。

最后都没找到，返回 `PERM_NONE`（0，无权限）。

> 注意：这个函数读的是**插件自己存的权限**（通过 nvault）。但实际发放命令里，还会用 `get_user_flags(id) & ADMIN_IMMUNITY` 检查 AMXX 官方管理员权限。两套机制配合使用。

## 8.2 权限检查的通用写法

发放命令里反复出现这个模式：

```pawn
new iPermLevel = get_user_perm_level(id);
if (iPermLevel < PERM_ADMIN && !(get_user_flags(id) & ADMIN_IMMUNITY)) {
    client_print(id, print_chat, "[SkinSystem] 只有管理员及以上才能发放皮肤");
    return PLUGIN_HANDLED;
}
```

拆解这个 `if`：
- `iPermLevel < PERM_ADMIN` —— 插件自定义权限 < 管理员（2）
- `!(get_user_flags(id) & ADMIN_IMMUNITY)` —— **不是** AMXX 官方管理员（`ADMIN_IMMUNITY` 是"免疫"权限，通常给最高管理员）
- 两个条件用 `&&`（且）连接：**两个都满足**（既不是插件管理员，也不是官方管理员）才拒绝

> 也就是说：**只要满足一个条件就放行**——要么插件权限 >= 管理员，要么是 AMXX 官方管理员。这是双保险。

## 8.4 菜单发放：/giveskin（第 1086-1446 行）

        // 全部发放模式 - 直接发放
        ...

## 8.5 命令行单个发放：/giveskinid（第 1455-1543 行）

命令格式：`/giveskinid <玩家名|#id> <T|CT|Knife> <皮肤名>`

```pawn
public cmdGiveSkinCmd(const id) {
    if (!is_user_connected(id)) return PLUGIN_CONTINUE;

    new iPermLevel = get_user_perm_level(id);
    if (iPermLevel < PERM_ADMIN && !(get_user_flags(id) & ADMIN_IMMUNITY)) {
        client_print(id, print_chat, "[SkinSystem] 只有管理员及以上才能发放皮肤");

    ...
    new iType = -1;
    if (equali(szTypeStr, "T") || equali(szTypeStr, "t")) { iType = 0; ... }
    else if (equali(szTypeStr, "CT") || equali(szTypeStr, "ct")) { iType = 1; ... }
    else if (equali(szTypeStr, "Knife") || equali(szTypeStr, "knife") || equali(szTypeStr, "刀")) { iType = 2; ... }

    }

    if (iSkinIndex == -1) {
        client_print(id, print_chat, "[SkinSystem] 找不到皮肤: %s (类型: %s)", szSkinName, szTypeStr);
        ...
        return PLUGIN_HANDLED;
    }

    if (has_skin(iTarget, iType, iSkinIndex)) {
        client_print(id, print_chat, "[SkinSystem] 玩家已拥有该皮肤: %s", szModelName);

    }

    give_skin(iTarget, iType, iSkinIndex);
    ...
}
```

几个关键点：

1. `cmd_target(id, szTargetName, CMDTARGET_OBEY_IMMUNITY | CMDTARGET_ALLOW_SELF)` —— AMXX 内置的玩家查找函数，支持名字和 `#id` 格式。`if (!iTarget)` 找不到就返回。
2. `if (iType == -1 || aModels == Invalid_Array)` —— **类型无效**（iType 还是 -1）或数组无效就报错。
3. 按皮肤名查找索引：`if (containi(szModelName, szSkinName) != -1)` —— 用**包含匹配**（不区分大小写），找到就 `break`。
4. `if (iSkinIndex == -1)` —— 找不到皮肤，列出所有可用皮肤。
5. `if (has_skin(...))` —— 已拥有就提示。

## 8.6 服务器命令：srvCmdGiveAllSkins / srvCmdGiveSkinMenu（第 679-754 行）

这两个是 `register_srvcmd` 注册的服务器命令，供菜单内部通过 `server_cmd` 调用。

```pawn
public srvCmdGiveAllSkins() {
    new szUserId[8], szType[16];
    read_argv(1, szUserId, charsmax(szUserId));
    read_argv(2, szType, charsmax(szType));

    new id = find_player("k", str_to_num(szUserId));
    if (!id || !is_user_connected(id)) return PLUGIN_HANDLED;

    if (equali(szType, "T")) {
        new iTotal = ArraySize(g_aTModels);
        g_iOwnedTCount[id] = 0;
        for (new i = 0; i < iTotal && i < MAX_OWNED_SKINS; i++) {
            g_iOwnedT[id][i] = i;
            g_iOwnedTCount[id]++;
        }
        if (g_iSelectedT[id] < 0) g_iSelectedT[id] = 0;
        save_player_skins(id);
        client_print(id, print_chat, "[SkinSystem] 管理员已发放全部T皮肤给你(%d个)", iTotal);
    }
    ...
}
```

`read_argv` 读取服务器命令的参数。`find_player("k", str_to_num(szUserId))` —— 按 userid 查找玩家（`"k"` 表示按 userid）。

> 注意 `for (new i = 0; i < iTotal && i < MAX_OWNED_SKINS; i++)` —— 循环条件里有两个限制：`i < iTotal`（不超过皮肤总数）**且** `i < MAX_OWNED_SKINS`（不超过最大拥有数）。这个 `&&` 是**双重保护**，防止数组越界。

## 8.7 小结

管理员发放的完整体系：

```
命令行：
  /giveallskins <玩家> <类型>   → 批量发放
  /giveskinid <玩家> <类型> <皮肤> → 单个发放
菜单：
  /giveskin → 选玩家 → 选方式 → 选类型 → 选皮肤
权限：
  插件权限 >= 管理员 或 AMXX 官方管理员，否则拒绝
```
